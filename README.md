# plan-manager

**Talk to your projects. The AI runs the rest.**

plan-manager turns project orchestration into a conversation. You say what you
want in plain language — "show me an overview", "add a task to X", "run the next
one" — and the assistant drives every script, panel, and state change for you.
Built for Claude Code, Codex CLI, and Copilot CLI.

## Why plan-manager

- **Conversational UX** — no commands to memorize. State intent; the AI
  translates it into the right action and shows you the result.
- **Dual-role** — a `strategist` role for planning and review, an `executor`
  role for autonomous task execution. Switch anytime.
- **Panel-centric** — every dashboard (overview, tasks, ready-queue, config,
  trash, GitHub status…) is a script-generated panel you can call by name.
- **Safe writes** — all metadata changes go through scripts: previewed first,
  applied on confirm. Deletes go to a restorable trash, never `rm`.
- **Cross-project orchestration** — task priorities, dependencies, and a
  deterministic ready-queue across all your projects.

## How you use it

You drive plan-manager by **talking to the assistant**. You never have to type a
CLI command or learn flags — describe the outcome, the assistant does it.

```text
You:  show me an overview
AI:   <renders the global project panel>

You:  add a task to plan-manager — tighten the docs
AI:   <creates the task, asks for priority/details, confirms>

You:  switch to executor and run the next ready task
AI:   <executes the approved plan step by step, checkpoints, reports>

You:  what's in the trash?
AI:   <lists soft-deleted items; "restore X" brings it back>
```

Unsure where to start? Just say **`help`** (or `/plan-manager help`) for a
role-aware quick flow.

## Dual-role model

| Role | Does | Best for |
|------|------|----------|
| **strategist** | Analyze projects, review plans, draft plans, set goals | Kickoff, review, replanning |
| **executor** | Run approved tasks (Ralph-style loop), auto-checkpoint, auto-continue | Daily work, overnight runs |

Say "switch to strategist" / "switch to executor" to change roles. Drafting a
new plan is strategist-only; executing it is executor-only — you approve every
plan before it runs.

## Panels

Dashboards are **panels** generated by scripts. Three kinds:

- **fixed** — built-in, always available: `help`, `config`, `overview`,
  `projects`, `tasks`, `ready-queue`, `remote`, `github-status`, `trash`,
  `panels`.
- **saved** — your own named panels, persisted for reuse.
- **temporary** — one-off panels generated on the fly during a conversation.

Call any panel by name: "show tasks", "open the config panel", or
`/plan-manager <name>`.

## Install

### Claude Code Plugin (recommended for Claude Code)

From within Claude Code:

```
/plugin marketplace add wangyuncepu/plan-manager
/plugin install plan-manager@plan-manager
```

Skill auto-registers immediately — no reload needed.

### Claude Code Manual (git clone)

```bash
git clone https://github.com/wangyuncepu/plan-manager.git
cd plan-manager
bash install.sh --target claude --mode symlink
/reload-plugins
```

`install.sh` creates a symlink or copy from the selected CLI skill directory to this repo. For Claude Code default: `~/.claude/skills/plan-manager` → this repo. Use `--target codex` or `--target copilot` for other CLIs.

### Codex CLI Plugin

From within Codex CLI:

```text
/plugins
```

Add this repository as a plugin marketplace if it is not listed yet:

```bash
codex plugin marketplace add wangyuncepu/plan-manager
```

Then search for `plan-manager` in `/plugins` and select `Install Plugin`.

The Codex plugin manifest lives at `.codex-plugin/plugin.json` and loads `skills/plan-manager`.

### Codex CLI Skill (manual)

Codex CLI can load standalone skills from `~/.codex/skills/`.

```bash
git clone https://github.com/wangyuncepu/plan-manager.git
cd plan-manager
mkdir -p ~/.codex/skills
ln -s "$(pwd)/skills/plan-manager" ~/.codex/skills/plan-manager
```

If `~/.codex/skills/plan-manager` already exists, remove it first:

```bash
rm -rf ~/.codex/skills/plan-manager
```

If your Codex CLI environment does not support symlinked skills, copy the directory instead:

```bash
cp -R skills/plan-manager ~/.codex/skills/plan-manager
```

Restart Codex after installing. Invoke the skill with:

```text
$plan-manager
```

or open `/skills` and select `plan-manager`.

### Copilot CLI Plugin

copilot plugin marketplace add wangyuncepu/plan-manager

## Quick start

After installing, just talk to the assistant:

```text
configure plan manager       → set the management root (one-time)
show overview                → see all projects
create project <name>        → register a project, set its goal together
add task to <project>        → create a task
make plan for <task>         → strategist drafts a plan; you approve
switch to executor → run     → execute the approved task
help                         → role-aware guide + what to say
```

## Modules

| # | Module | Role |
|---|--------|------|
| 1 | **Project** | Project registry, lifecycle (active/idle/completed/archived) |
| 2 | **Task** | Task CRUD, priority/dependency ordering, 1 active per project |
| 3 | **Plan** | Mandatory `plan.md` per task, approval before execution |
| 4 | **Execute** | Run top-ranked tasks across N projects (executor role) |
| 5 | **Check** | Loop detection, auto-checkpoint, state persistence, crash recovery |
| 6 | **Assistant** | Dashboards, suggestions, role-aware guidance |
