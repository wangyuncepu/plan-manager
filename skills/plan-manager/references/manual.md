# plan-manager Manual

plan-manager is a panel-centered project orchestration skill. It manages projects, tasks, plans, execution state, GitHub remotes, and trash through scripts.

## Start here

Unsure what to do? Open the help panel — it adapts to the current role and lists the quick flow + every command:

```bash
~/.claude/skills/plan-manager/scripts/panel-manage.py run help
# or: /plan-manager help
```

### Quick start — strategist (plan)

```text
1. /plan-manager                 see global overview
2. analyze <project>             study state, gaps, direction
3. create project <name>         project-manage.py create ... (dry-run → --apply)
4. add task to <project>         task-manage.py create ...
5. make plan for <ID>            draft plan.md → you approve
6. switch to executor            switch role to run work
```

### Quick start — executor (run)

```text
1. /plan-manager ready-queue     view ready tasks
2. switch to executor
3. execute / auto                run ready tasks
4. continue                      resume from checkpoint
```

### Where do I start? (scenario → command)

| Goal | Command |
|------|---------|
| See state | `/plan-manager` or `panel-manage.py run overview` |
| New project | `project-manage.py create --root <root> --name <name> [--apply]` |
| New task | `task-manage.py create --root <root> --project <p> --title <t> [--apply]` |
| Run tasks | `switch to executor` → `execute` / `auto` |
| Resume | `continue` |
| Undo a delete | `trash-manage.py list` → `restore <name> --apply` |
| Purge trash | `trash-manage.py purge <name> --force --apply` |
| Configure | `configure-plan-manager.sh ...` (or `--show`) |
| Save a panel | `panel-manage.py add <name> ... --apply` |

## Mental model

Use panels first:

- fixed panels: stable dashboards generated by scripts
- saved panels: common panels persisted in `~/.claude/plan-manager/panels.json`
- temporary panels: one-off panels generated during a conversation

Use scripts for writes:

- Project metadata writes go through `project-manage.py`.
- Task metadata writes go through `task-manage.py`.
- GitHub remote writes go through `github-manage.sh`.
- Trash restore/purge goes through `trash-manage.py`.
- Most write operations are dry-run by default. Add `--apply` only after checking the output.

## Configuration

Show current config:

```bash
~/.claude/skills/plan-manager/scripts/config-panel.py --lang zh
~/.claude/skills/plan-manager/scripts/configure-plan-manager.sh --show
~/.claude/skills/plan-manager/scripts/panel-manage.py run config
```

Configure root, language, role, and GitHub owner:

```bash
~/.claude/skills/plan-manager/scripts/configure-plan-manager.sh \
  --root /home/wangyu/ClaudeCodeCLI \
  --language zh \
  --role strategist \
  --github-enabled true \
  --github-owner wangyuncepu
```

Config file:

```text
~/.claude/plan-manager/config.json
```

Important fields:

| Field | Meaning |
|---|---|
| `root` | Management root containing `project/` |
| `role` | `strategist` or `executor` |
| `language` | `zh` or `en` |
| `parallelism` | Number of projects/tasks to run in parallel |
| `autonomy` | Interaction level |
| `github.enabled` | Show GitHub remote panels |
| `github.owner` | GitHub user/org for expected repos |

## Saved and temporary panels

Save a commonly used panel:

```bash
~/.claude/skills/plan-manager/scripts/panel-manage.py add weekly \
  --script project-overview.py \
  --title "Weekly Overview" \
  --description "每周总览" \
  --args '["--root","$ROOT","--lang","$LANG"]'
```

Apply the save:

```bash
~/.claude/skills/plan-manager/scripts/panel-manage.py add weekly \
  --script project-overview.py \
  --title "Weekly Overview" \
  --description "每周总览" \
  --args '["--root","$ROOT","--lang","$LANG"]' \
  --apply
```

Run it:

```bash
~/.claude/skills/plan-manager/scripts/panel-manage.py run weekly
```

Remove it:

```bash
~/.claude/skills/plan-manager/scripts/panel-manage.py remove weekly --apply
```

Generate a temporary panel without saving:

```bash
~/.claude/skills/plan-manager/scripts/panel-manage.py generate \
  --script project-overview.py \
  --args '["--root","$ROOT","--lang","$LANG","plan-manager"]'
```

## Execution workflow

Show ready queue:

```bash
~/.claude/skills/plan-manager/scripts/ready-queue.py --root /home/wangyu/ClaudeCodeCLI
```

Execution rules:

- Switch to executor before running tasks.
- Executor should start tasks with `task-manage.py start`.
- Executor should complete tasks with `task-manage.py complete`.
- File writes during task execution stay inside the active task directory unless the plan has an explicit `write-exception`.
