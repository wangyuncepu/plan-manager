# Panel Integration

plan-manager treats dashboards as panels.

## Panel Types

- Fixed panels: built-in panels generated by stable scripts (`overview`, `projects`, `tasks`, `ready-queue`, `remote`, `github-status`, `trash`, `panels`).
- Saved panels: user-defined panel definitions persisted in `~/.claude/plan-manager/panels.json`.
- Temporary panels: one-off script calls generated during conversation via `panel-manage.py generate`.

## Registry

The registry lives at:

```text
~/.claude/plan-manager/panels.json
```

Fixed panels are supplied by `panel-manage.py` even when the file is missing. Saved panels are written only with explicit `--apply`.

## Commands

```bash
panel-manage.py list
panel-manage.py show <name>
panel-manage.py run <name>
panel-manage.py add <name> --script <script> --title <title> --description <desc> --args '[...]' --apply
panel-manage.py remove <name> --apply
panel-manage.py generate --script <script> --args '[...]'
```

## Variables

Panel args support these variables:

- `$ROOT` — `config.root`
- `$LANG` — `config.language`
- `$GITHUB_OWNER` — `config.github.owner`

## Safety

Panel definitions only execute scripts in `skills/plan-manager/scripts/`. Mutating saved panel definitions is dry-run by default; `--apply` is required.
